# 語縁 GOEN：水彩背景の配置改善プロンプト

## 目的
白背景と京都の水彩画を維持し、水彩がセクション最下部まで見えない問題と、モバイルでの存在感不足を解消する。

## 作業指示
1. AGENTS.mdと現在の実装・Git公開先を確認。最新の goen-hp-main を編集元とし、公開作業コピーとの差分を限定する。
2. TOPの見出し・動画カルーセル・操作位置・CTAは変更しない。各セクションの文章・リンク・画像データ・順序も維持する。
3. 既存の水彩画像を再生成せず、CSSの配置とトリミングで京都のモチーフを引き出す。白い紙の余白を含む画像全体を縮小するだけにしない。
4. PCは見出し右側に水彩の大きなビジュアルを配置し、セクションに入った時点で題材が見えるようにする。本文は背景より上のレイヤーに保ち、絵の縁を白へ自然になじませる。
5. モバイルは独立設計。各セクション冒頭に約200pxの全幅水彩ビジュアルを置き、その直下に見出しと本文を配置する。画像と本文を無理に重ねず、最初の画面内で絵と見出しを認識できる構成にする。
6. 竹林・町家・飛び石・茶畑・円窓・庭・橋などの位置に応じてセクション別にトリミングを設定。写真や動画に同じフィルターを適用しない。
7. 長い空白、新たなカードUI、過剰なアニメーション、外部ライブラリを追加しない。水彩の色味と白背景を保つ。
8. 装飾画像のaria-hidden、alt空文字、lazy loading、寸法指定を維持。ビジュアル領域の高さをCSSで予約し、CLSと横はみ出しを防ぐ。
9. index.htmlとgoen-line.htmlの差分はモバイル転送スクリプトのみ。CSSキャッシュバスターを更新。
10. 1440/1920px、390/375pxで全セクション冒頭のスクリーンショットを確認。画像読込、白背景、横はみ出し、コンソールエラー、TOP不変を検証する。
11. 今回のユーザー指示には本番反映が含まれる。検証後、指定のorigin mainへ今回の変更のみを公開し、本番でも検証する。

## 完了基準
- PCは見出し横、モバイルは見出し前に水彩が見える。
- 本文を読む前に京都らしい題材が認識できる。
- TOPと既存コンテンツに変更がない。
- 白背景・画像の色味・モバイルの可読性が維持される。
- 本番のPC/モバイルで画像が正常に表示される。
