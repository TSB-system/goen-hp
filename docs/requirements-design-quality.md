## 0. サマリー（この文書で決めたこと）

1. **方向性は変えず、密度を上げる。** 現在の「墨黒 × アイボリー × 深緑 × 金」「線と余白で導く」というコンセプトは、直接競合（オレンジ・紺・白基調の "業者サイト"）に対して既に差別化できている。捨てずに磨く。
2. **足りないのは「人」と「証拠」。** 競合上位は例外なく「代表の顔」「数字」「事例」「声」で信頼を作っている。語縁は Works が「準備中」、代表の顔・声が一切なく、"美しいが匿名" の状態。ここが最大の弱点。
3. **代表=現役インフルエンサーという唯一の武器を、動画で見せる。** `動画/` に 8 本の素材（HP(1)〜(8).mov）があり、8/27 のプレビュー（`local-preview-current.png`）にはスマホ縦動画カルーセルの FV 案も存在する。これを正式要件に組み込み、FV と INSIGHT で使う。
4. **質の差は「細部」で出る。** タイポの級数体系、行間、字間、罫線の太さ、余白の比率、モーションの秒数・イージングの統一、ホバー/フォーカスの反応、画像の色調統一。これらをトークン化し、全セクションで例外を作らない。
5. **速度と実装品質もデザインの一部。** LCP < 2.5s / CLS < 0.1 / INP < 200ms、Lighthouse Performance 90+ を受け入れ基準に含める。

## 3. デザインコンセプト（改訂版）

**コンセプト：「線と余白で導く」→「線と余白と、人で導く」**

- **線**：一本の導線（rail / growline / boundary-line）。既存資産。精度と統一を上げる。
- **余白**：和の呼吸。セクション上下・見出し周りの余白を "比率" で定義し直す。
- **人**：代表の顔・声・動画・数字。匿名性を捨てる。

### 3.1 「静」のサイトに「動」の代表 — 安さと完成度を両立させる見せ方

代表の言葉は次の 3 行である（原文ママ、v1.1 で確定）。

> 日本一安いホームページ制作会社を目指してます。
> 値段以上のホームページお作りします。
> 完成度も負けません。

これは §2 で定義した「上質 × 信頼」の上質側と一見ぶつかる（"安い" を前面に出すと業者感が出る）。しかし、代表の素材（法被姿で大きく手足を広げた透過写真＝**動**）と、既存サイトの静かな和モダン（＝**静**）を対比させると、**「こんなに安いのに、こんなに完成度が高い」をサイト自体が証明する**構図になる。よって次の原則で両立させる。

| 原則 | 具体 |
|---|---|
| サイトの器は「静」を崩さない | 配色・書体・余白・線は §4 のまま。安さを色（赤・黄）や大文字で叫ばない |
| 代表は「動」で出す | 透過の全身写真、動画、SNS の数字。表情と勢いはそのまま使う |
| 「安い」は代表の一人称で語る | 「日本一安い〜を目指してます」は代表の言葉として引用符付きで掲載。サイトの見出し（H1/H2）には使わない |
| 「完成度」はサイトそのもので示す | Works と、このサイトの仕上がりが証拠。言葉で「高品質」と繰り返さない |
| 表現上の注意 | 「日本一安い」は最上級表現のため、必ず「目指しています」を伴う目標表現とし、断定形（「日本一安い会社です」）にしない。フォロワー・再生数は「2025 年 10 月時点」「1 年で」など時点を添える |

**トーン＆マナー**

| 軸 | 定義 |
|---|---|
| 印象 | 静かな高級感 / 誠実 / 現代的な和 — その中に、よく笑う代表がいる |
| 例え | 京都の老舗の帳場に、法被を着た若い当主がいる |
| やること | 余白を恐れない。線は細く、金は少なく。人は大きく |
| やらないこと | 派手な色、装飾フォント、飾り罫の多用、過剰な影、バウンス系イージング、「安い」の連呼 |

## 4. デザインシステム要件

### 4.1 カラー

既存トークンは維持。以下を追加・明文化する。

| トークン | 値 | 用途 |
|---|---|---|
| `--ink` `--ivory` `--green` `--gold` 系 | 既存 | 変更しない |
| `--surface-0` | `var(--ivory)` | 基本面 |
| `--surface-1` | `var(--ivory-2)` | 交互セクション（Problem / Flow / About） |
| `--surface-2` | `var(--paper)` | カード・引用 |
| `--surface-dark` | `var(--ink)` | Insight（既存）+ Contact 上部帯（新規） |
| `--surface-green` | `var(--green-deep)` | 1 箇所のみ使用可（Works の帯 or Plans 強調） |
| `--text-on-dark` | `var(--ivory)` | 暗色面の本文 |
| `--muted-on-dark` | `rgba(244,239,228,.62)` | 暗色面の補助 |

**ルール**
- 金 `--gold` は「線・番号・ラベル・アクセント 1 語」にのみ使う。面には使わない。
- 緑はボタンと 1 セクションのみ。緑面を増やさない。
- セクション背景のリズムを固定する：
  `Hero(暗/動画) → Quality(ivory) → Problem(ivory-2) → System(ivory) → Service(ivory) → Works(paper 帯) → Insight(ink) → Plans(ivory) → Flow(ivory-2) → FAQ(ivory) → About(ivory-2) → Contact(ink 上帯 + ivory) → Footer(ink)`
- コントラスト：本文 AA（4.5:1）以上、ラベル・ゴーストは装飾扱いで可。

### 4.2 タイポグラフィ

書体は既存 4 系統を維持。**級数体系を fluid scale で固定**する。

| ロール | 書体 | サイズ（PC） | サイズ（SP） | 行間 | 字間 |
|---|---|---|---|---|---|
| Display（H1） | Shippori Mincho 500 | `clamp(44px, 5.2vw, 76px)` | `clamp(34px, 9.5vw, 42px)` | 1.25 | -0.01em |
| H2 | Shippori Mincho 500 | `clamp(30px, 3.2vw, 44px)` | `clamp(24px, 6.8vw, 30px)` | 1.45 | 0 |
| H3 | Noto Sans JP 500 / Shippori 500 | 20–22px | 18px | 1.6 | 0.01em |
| Lead | Noto Sans JP 400 | 17–18px | 16px | 1.9 | 0.02em |
| Body | Noto Sans JP 400 | 15–16px | 15px | 1.95 | 0.02em |
| Caption / Note | Noto Sans JP 400 | 13px | 12–13px | 1.7 | 0.02em |
| Label（EN） | Cormorant Garamond 500 / Jost 500 | 11–12px | 11px | 1 | 0.22em（`--tracking-label`） |
| Number | Spectral 300 | 文脈依存 | | 1 | 0.04em |
| Ghost（背景英字） | Cormorant Garamond 300 | `clamp(120px, 16vw, 220px)` | 非表示 or 80px | 1 | -0.02em |

**ルール**
- 日本語見出しは `font-feature-settings: "palt"` + `text-wrap: balance`（対応ブラウザ）。禁則で不自然な改行が出る箇所は `<br>` で制御（現状踏襲）。
- 明朝と和文ゴシックを同一行で混在させない。
- 英字ラベルは必ず大文字 + `--tracking-label`。
- 数字は `font-variant-numeric: tabular-nums`（ステップ番号・カウンター）。
- フォントは `preload` + `font-display: swap`。Google Fonts の読み込みウェイトを **実際に使うものだけ**に絞る（現状 Cormorant 6 ウェイト等は過剰）。

### 4.3 グリッド・余白

| トークン | PC | SP |
|---|---|---|
| `--maxw` | 1180px（既存） | — |
| `--gutter` | `clamp(22px, 6vw, 110px)`（既存） | 22–24px |
| `--sec-pad-y` | `clamp(112px, 12vw, 176px)` | `clamp(72px, 18vw, 96px)` |
| `--head-gap` | 見出しブロック → 本文：`clamp(40px, 5vw, 72px)` | 32px |
| `--row-gap` | リスト行間：`clamp(28px, 3vw, 40px)` | 22px |
| 2 カラム比 | `5fr 7fr`（statement / body）に統一 | 1 カラム |

**ルール**
- セクション内の余白は 8px ベースの倍数（8 / 16 / 24 / 32 / 40 / 56 / 72 / 96 / 128）。
- 見出しブロック（`.head`）の高さと本文の開始位置を全セクションで揃える。
- 2 カラムの左カラムは PC で `position: sticky`（Quality / Insight / Contact）。

### 4.4 線・面・影

- 罫線は 1px のみ。`--line-on-light` / `--line-on-dark` の 2 種（既存）で統一。太い罫線・二重罫線は使わない。
- 金線（`.boundary-line` / `.flow-line`）は **1 セクションに 1 本まで**。
- 角丸：0（線コンセプトのため）。ボタンも直角。例外はレール上のビーズ・ドットのみ。
- 影：`--shadow-soft` のみ。使用箇所は浮いた要素（動画フレーム・スティッキーバー・ドロワー）に限定。

### 4.5 モーション

既存トークン（`--dur-*` / `--ease-*`）を維持し、**使い方の規約**を追加する。

| 種類 | 値 | 用途 |
|---|---|---|
| Reveal | `--dur-base` 0.8s / `--ease-out` / y: 20px → 0 / blur 6px → 0 | 全要素の登場 |
| Stagger | 80ms 刻み（最大 6 要素） | リスト行 |
| Line draw | `--dur-slow` 1.0s / `--ease-inout` / scaleX 0 → 1 | 罫線・金線 |
| Hero | `--dur-hero` 1.6s | FV のみ |
| Hover | `--dur-fast` 0.4s / `--ease-out` | ボタン・行・カード |
| Instant | `--dur-instant` 0.2s | フォーカス・アクティブ |

**ルール**
- イージングは 2 種類のみ。バウンス・エラスティック禁止。
- スクロール連動（scrub）は「レール進捗」「導線の伸び」「FV パララックス」の 3 つに限定。
- `transform` / `opacity` / `clip-path` / `filter` 以外をアニメーションしない（レイアウトシフト防止）。
- `prefers-reduced-motion: reduce` で全てのモーションを即時表示に（既存踏襲）。
- 登場アニメーションは `once: true`（既存）。番号点灯のみ往復可。

**追加するマイクロインタラクション**

| 要素 | 挙動 |
|---|---|
| `.btn` | 背景が左から右へ流れる（既存 `::before`）+ 矢印が 4px 右へ + 押下で 0.98 倍 |
| `.index-row` / `.plan-row` | ホバーで行全体の背景が `--surface-2` に、番号が金に、右端に「→」がフェードイン |
| `.faq__q` | `+` が 45° 回転して `×` に。開閉は `grid-template-rows: 0fr → 1fr`（既存の maxHeight 方式から移行し、resize 追従を不要にする） |
| ナビリンク | 下線が中央から左右に伸びる。現在地セクションに `aria-current` + 金ドット |
| 数字（実績） | ビューポート進入時に 1.2s でカウントアップ（reduced-motion 時は即表示） |
| 見出し H2 | 行単位で 60ms ずらして立ち上がる（`<span>` 分割は `<br>` 単位でのみ。文字単位分割はしない） |

| 長さ | FV 用は各 8〜12 秒にトリム、ループ前提。Insight 用は 30 秒以内 |
| ビットレート | 目標 1.5〜2.5 Mbps、**1 本あたり 3MB 以下**。8 本合計 20MB 以下 |
| 音声 | FV 用は音声トラック削除（ミュート autoplay 要件）。Insight 用は音声あり、初期ミュート |
| poster | 各動画の先頭フレームを AVIF/WebP で書き出し |
| 読み込み | FV の中央 1 本のみ `preload="metadata"`、他は `preload="none"` で、ユーザー操作 or `IntersectionObserver` で順次ロード |
| 属性 | `autoplay muted loop playsinline` + `poster` + `aria-label` |
| 省電力対応 | `prefers-reduced-motion` または Data Saver 時は poster のみ表示 |
| 配置先 | `assets/video/fv-01.mp4` … `fv-08.mp4`、`assets/video/insight-01.mp4`。**元 .mov（合計 872MB）はリポジトリに含めない**（`.gitignore` / `.vercelignore` に `動画/` と `*.mov` を追加） |
| 変換例 | `ffmpeg -i "動画/HP(1).MOV" -t 10 -vf "scale=720:1280:force_original_aspect_ratio=increase,crop=720:1280" -c:v libx264 -crf 26 -preset slow -an -movflags +faststart assets/video/fv-01.mp4` |

**選定基準**：テロップ入り・顔がはっきり・京都の景色が入るカットを優先。8/27 プレビューの「【元・おいでやすのカメラマン】※無料でホームページ作らせて下さい」のような **既に投稿済みの実績動画**は "見られる側を知っている" の証拠になるので優先度が高い。

### 6.3 画像最適化

- 全画像を AVIF + WebP + フォールバック（PNG/JPG）で `<picture>` 配信。
- `srcset` で 1x / 2x（PC）、480 / 768 / 1080（SP）。
- 装飾画像は `loading="lazy"` `decoding="async"`。FV の LCP 要素のみ `fetchpriority="high"`。
- ロゴは SVG 化（`goen-logo.png` 539×539 をトレース）。
- OG 画像：1200×630 を新規作成（代表 + ロゴ + タグライン）。`og:image` は**絶対 URL**に修正。

## 8. パフォーマンス・アクセシビリティ・SEO 要件

### 8.1 パフォーマンス（受け入れ基準）

| 指標 | 目標 | 測定 |
|---|---|---|
| LCP | < 2.5s（PC / SP、Slow 4G スロットル） | Lighthouse + PageSpeed Insights |
| CLS | < 0.1 | 同上 |
| INP | < 200ms | 同上 |
| Lighthouse Performance | 90+（PC）/ 85+（SP） | 同上 |
| 初期転送量 | < 1.2MB（FV 動画 1 本含む） | DevTools Network |
| フォント | 使用ウェイトのみ。合計 < 400KB。`preload` 2 ファイルまで | — |
| JS | GSAP + ScrollTrigger + 自前 JS の合計 < 120KB（gzip）。`defer` 維持 | — |

### 8.2 アクセシビリティ

- 見出し階層：H1 1 つ、各セクション H2、項目 H3（既存踏襲）。
- 全インタラクティブ要素に `:focus-visible` スタイル（既存の金アウトラインを維持）。
- FAQ：`aria-expanded` / `aria-controls` / `id` の対応を完全に。
- 動画：`aria-label` と、音声あり動画には字幕（`<track kind="captions">`）or 隣接テキストで同内容。
- コントラスト：本文 4.5:1、大見出し 3:1 以上。ゴースト文字は `aria-hidden`。
- `prefers-reduced-motion` で全モーション停止（既存踏襲）。
- キーボードのみで全 CTA に到達可能。ドロワー内はフォーカストラップ。

### 8.3 SEO / シェア

- `<link rel="canonical">`（PC / SP それぞれ `https://goen-enishi.vercel.app/` 系の絶対 URL）。
- `og:image` / `twitter:image` を絶対 URL、1200×630。
- `favicon.svg` + `apple-touch-icon.png`（180）。
- JSON-LD：`Organization`（or `LocalBusiness`）+ `FAQPage`。
- `title` は現状維持（40 字前後・訴求が明確）。`meta description` は 120 字以内に短縮。
- SP 版は `rel="alternate"` ではなく、PC/SP を同 URL で提供できるまでは `canonical` を PC に向ける（重複コンテンツ回避）。
